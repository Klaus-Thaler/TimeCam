# Hide an old smartphone as a time-lapse.

The app is resource-intensive, as the camera must remain active from the outset.

The first loop can run for several hours. After that, a steady cycle is maintained for the time-lapse.

In the main function, the device’s Wi-Fi and Bluetooth are disabled. All audio streams are set to zero.

The display is configured without a navigation bar. All key information is shown on the display.
